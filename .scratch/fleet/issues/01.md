# 01: The core knows each agent

**What to build:** the core answers the fleet: every agent the replica has seen, with the person it acts for, the task it holds and its lease, whether its lease lapsed, whether it failed recently, and its latest channel. It follows the replica.

**Blocked by:** Tasks 01

**Status:** ready-for-agent

- [ ] An agent is an actor of kind `agent`; people are left out.
- [ ] Lapsed means its latest claim ended in `task.expired`, or its `until` has passed while the board says claimed; failed recently means a task it held failed in the last hour.
- [ ] The contract gains the fleet's subscription.
- [ ] Tests come first, against the fake board's history.
