# 02: The Tasks lens

**What to build:** the sidebar gains Tasks. It lists every task, open ones first, in windows of fixed 30 px rows with the concept's columns: state, task, channel, owner, held by with a lease bar, and last change. Chips per state with their counts narrow it, a box filters by title, and the sidebar's channel narrows it too. Selecting a row opens the task's thread.

**Blocked by:** 01, Flow 01

**Status:** ready-for-agent

- [ ] The core answers windows of the ordered, narrowed task list, and the chips' counts, and follows the replica.
- [ ] Leases count down in the UI and read as lapsed once past.
- [ ] Tests come first: order, counts and filters in the core; the lens against the fake core.
- [ ] Verified by hand on a board of 10,000 tasks made with `vb tasks create --file`: narrowing and scrolling stay under 50 ms.
