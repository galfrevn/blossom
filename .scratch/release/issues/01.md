# 01: A command that measures every budget

**What to build:** `bun run measure` generates a board of 100,000 messages with `vb serve` in a temporary folder, builds the app in a measuring mode, and measures cold start, frames while the list scrolls itself, jumps, and memory across the app and its WebKit processes, over several runs. It prints each against ADR 0009 and fails when one breaks.

**Blocked by:** Flow 02

**Status:** ready-for-agent

- [ ] The measuring mode is compiled only into that build; the release carries none of it.
- [ ] Memory is read with `footprint` for the app and the WebKit processes it started.
- [ ] Its results are added to `documentation/research/list.md`.
- [ ] It runs by hand; CI does not run it.
