# 02: Get a hosted board's token through the Vercel CLI

**What to build:** for a board whose discovery names a Vercel team and project, the core gets a token as ADR 0022 says: Board's cache first, else `vercel api` and `vercel project token`, exchanged at `oidc.vercel.com` and written back in Board's format. A missing or expired login is reported with `vercel login` as the fix.

**Blocked by:** Boards 03

**Status:** ready-for-agent

- [ ] Board's cache is read and written in Board's own file names, JSON and permissions.
- [ ] The Vercel login is never read or written.
- [ ] The token never reaches the replica, the page or a log.
- [ ] Tests come first, against a fake Vercel API, a fake OIDC endpoint and a fake `vercel` executable.
- [ ] Verifying it end to end waits for ticket 01's hosted board.
