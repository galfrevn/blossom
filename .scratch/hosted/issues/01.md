# 01: Measure what reading a hosted board costs

**What to build:** against a real hosted board, measure what each kind of read costs in Vercel API requests and time: one channel's threads, a thread's replies, a page of the feed. Measure how far back the feed reaches and whether it reads across channels. Record the rate limit the person's login has. Extrapolate a whole copy of 100,000 messages from a sample, and recommend how the first copy should go.
