# 08: A tag publishes the disk image

**What to build:** the owner raises the version, pushes a tag such as `v0.2.0`, and a few minutes later a GitHub prerelease holds the disk image, its checksum and release notes written from the commits since the last tag. Anyone can verify where the image was built. It costs nothing.

**Blocked by:** 06

**Status:** wontfix

Deferred by the owner on 2026-11-21: releases wait until distribution is decided (ADR 0012). Nothing here is built and ADR 0012 is not edited. When distribution is decided, set this ticket back to `ready-for-agent`. The design below still applies.

- [ ] A `release.yml` workflow runs on tags `v*.*.*`, on `macos-latest`. It asks for `contents: write`, `id-token: write` and `attestations: write`, and nothing else does.
- [ ] It fails when the tag does not match the version in `desktop/Cargo.toml`, which is the version Tauri gives the app.
- [ ] It builds the disk image with the same command and checks as CI, the installer budget included.
- [ ] The image is signed ad hoc, so that on Apple Silicon macOS offers "Open Anyway" instead of calling it damaged. Verify this with a downloaded, quarantined copy on a Mac that did not build it.
- [ ] The release holds the disk image and a SHA-256 checksum. It is marked as a prerelease while the version is below 1.0.
- [ ] Release notes come from the Conventional Commits since the previous tag, through git-cliff, grouped by type.
- [ ] A build provenance attestation is published for the disk image, and `gh attestation verify` accepts it.
- [ ] The release notes say how to open an unsigned app.
- [ ] Once the owner has confirmed, ADR 0012's Distribution section is amended: until there is an Apple Developer account, tagged builds are published unsigned as prereleases on GitHub Releases. Signing and notarization plug into this workflow later as secrets.
- [ ] The first tag is pushed by the owner, not by an agent.

## Notes

- There is no updater. ADR 0013 forbids update checks unless a decision makes one visible to the person.
- Releases are built for Apple Silicon only. Intel and universal builds are out of scope (spec).
