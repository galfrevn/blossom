# 05: The app follows boards as they start and stop

**What to build:** with Blossom open, the operator starts `vb serve`, and within about a second the app opens that board without a restart. When they stop it, the app goes back to "no board running". When a newer board starts while one is open, the newer one opens, and when it stops, the app falls back to the one still running.

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] The core notices token files appearing and disappearing within about a second. Whether it watches the folder or polls it is chosen here, and the reason is written down in this ticket.
- [ ] The trigger that makes the core look again is injectable, so no test sleeps.
- [ ] Core tests come first: a board starts while subscribed; the open board stops; a newer board starts while one is open; the newer one stops and the older one opens again.
- [ ] A UI test asserts that the screen changes when the fake core pushes a new value.
- [ ] Verified by hand: start and stop `vb serve` with the app open.
