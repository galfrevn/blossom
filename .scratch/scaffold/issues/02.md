# 02: The window opens

**What to build:** a contributor runs `bun run dev` and Blossom's window opens. It has its own title bar with the macOS window buttons inset, it can be dragged by that bar, and it shows no white flash in either theme. It is set in Geist and coloured by the identity's tokens, light or dark as the system says. The same UI also opens in an ordinary browser, and `bun run build` makes the installer.

**Blocked by:** 01. It also needs the identity's token file, `ui/theme/tokens.css`, which the identity session writes.

**Status:** ready-for-agent

- [ ] A `desktop` crate on Tauri 2, configured in `Tauri.toml`, with the identifier `io.github.galfrevn.blossom` and the product name Blossom. Its icons have one-word names, and it uses no Tauri plugins.
- [ ] A `ui` package on Vite (its config named `vite.ts`), React and TypeScript, with `strict`, `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes` and `verbatimModuleSyntax`. Biome formats and lints it, with `noExplicitAny` as an error, and Vitest finds tests in `tests` folders.
- [ ] Tailwind 4's theme points at the identity's CSS variables. The token file is imported as it is, and no value is copied out of it.
- [ ] Geist, Geist Mono and Geist Pixel are bundled from the `geist` package, and their license ships with the app.
- [ ] A content security policy lets the page load only its own bundled assets and talk only to the core over IPC.
- [ ] The window stays hidden until the UI has painted, and shows no white flash in light or dark.
- [ ] Capabilities grant only showing and dragging the window.
- [ ] The conventions check extends to TypeScript, read by a parser that understands JSX, and to CSS. Tests come first: a comment inside JSX is reported, and a URL in JSX text is not.
- [ ] `check` also runs Biome, the type check and Vitest.
- [ ] `bun run build` produces a disk image.
