# 03: CI and the two size budgets

**What to build:** every push and pull request is checked by GitHub Actions. A change that breaks a rule, a test or one of the two size budgets of ADR 0009 fails there, and every run prints both measured sizes, so a slow drift is visible before it breaks anything.

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] A Linux job runs everything in `check` that does not need macOS: the conventions check, the core's formatting, lints and tests, and the UI's lint, types, tests and build.
- [ ] A macOS job lints and builds the desktop shell and builds the disk image. It runs only what needs macOS, because macOS minutes cost ten times as much on a private repository.
- [ ] The JavaScript budget is the sum of the gzip sizes of the JavaScript files the UI build emits. The job fails above 250 KB.
- [ ] The installer budget is the size of the disk image. The job fails above 15 MB.
- [ ] Both sizes are printed on every run, passing or not.
- [ ] Locally, `check` still runs everything, so a green `check` predicts a green CI.
