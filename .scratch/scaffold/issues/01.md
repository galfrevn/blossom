# 01: Conventions check and workspace

**What to build:** a contributor runs one command, `bun run check`, and learns whether the repository follows the rules of `CLAUDE.md` that a machine can check. Every file and folder must be named with one lowercase word, and Rust files must have no comments. The Cargo and bun workspaces exist, ready for the next tickets to fill.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [x] A Cargo workspace at the root, on edition 2024 with `rust-version` pinned. Its lints are declared once: `unwrap_used` and `expect_used` denied outside tests, and `unsafe_code` forbidden.
- [x] A root `package.json` pins bun as the package manager. Its `check` script runs the conventions check, `cargo fmt --check`, Clippy with warnings denied, and the workspace's tests.
- [x] A development-only `conventions` crate checks every file git tracks or would track. Each path segment must be one lowercase word with an optional extension. Names a tool dictates are listed explicitly, and `.claude` and `.scratch` are outside the check.
- [x] It reports every comment in Rust files, doc comments and nested block comments included, using rustc's own lexer. It never reports a `//` inside a string.
- [x] Each report names the file, the line for a comment, and the rule broken. The command exits non-zero when there is any report.
- [x] Its behaviour is specified by tests written first, on small trees in temporary directories.
- [x] The repository passes its own check.
- [x] ADR 0017 gains a line for the development-only crate, and `CLAUDE.md` gains the rule for where tests go.

## Comments

Built on 2026-11-20, test-first: 13 tests in two files, one for names and one for comments. Notes for the next tickets:

- Clippy's `allow-unwrap-in-tests` covers `#[test]` functions and `#[cfg(test)]` modules, not the helpers of a shared support module in an integration test. Helpers there return `Result`, and the test unwraps.
- A misnamed folder is reported once, by its own path, not once per file inside it.
- The command exits 1 when it finds violations and 2 when it cannot run, for example when a listed Rust file cannot be read.
- Ticket 02 extends the comment check to TypeScript and CSS. The Rust lexer lives in its own module, ready to gain siblings.
- `CLAUDE.md` also gained "Done means `bun run check` passes", so agents run the whole check before calling work done.
