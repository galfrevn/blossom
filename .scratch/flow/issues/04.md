# 04: Progress folds into one line per channel

**What to build:** a run of agents' progress messages in a channel folds into one line: "#channel · 12 progress updates from 3 agents · latest: …". Opening the line shows its last messages in place. Anything that is not progress in that channel closes the fold.

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] The core folds over the sequence: a progress message is a reply in a task's thread, by an agent, with no mention, no attachment and no task change; a channel's fold grows until something else happens in that channel.
- [ ] A fold sits where its latest message sits, and a growing fold moves to the bottom.
- [ ] The fold's line reads as the concept draws it, and opens in place to show its last eight messages.
- [ ] Tests come first: each folding rule in the core, and the open and closed fold in the UI.
- [ ] Verified by hand on a board where several agents post progress in tasks' threads.
