## Comments

Built on 2026-11-21. The core gained 5 tests (the reader 4, keeping in step 1) and the UI 7.

- **Verified by hand** against `vb serve` holding 100,065 messages: the sidebar shows `fleet` with its 20 channels and the lens's header reads "Flow" in Geist Pixel. Memory with the frame shown: 82 MB across the app's four processes (the app 31, WebContent 35, GPU 11, networking 5).
- **The shell reads the replica through a read-only connection,** `ReplicaReader` in `core/src/reader.rs`. `keep_in_step` announces the replica it keeps, once it is named after its board, and the shell opens its reader then. During a first copy the tree is empty until the copy is named.
- **Channels are kept by a trigger** on new messages, into a `channels` table, so the write path is untouched. A replica made before rebuilds the table when it opens.
- **No counts on the channels.** The concept draws none; an unread mark comes later.
- **Natural order:** `area2` comes before `area10`, through `Intl.Collator` with numbers.
- **The detail pane moved to Thread 01, and the finder's box to Search 02.** An empty pane nothing opens, and a box that does nothing, would be the placeholders CLAUDE.md rules out.
- **Two placeholder ideas left the spec too:** the lens shortcuts' keys are drawn once the shortcuts exist (Search 04), and the lens's sentence about folding joins it with Flow 04.
