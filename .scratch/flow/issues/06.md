# 06: An empty board shows how to point an agent at it

**What to build:** a board with no messages shows, in Flow, the concept's notice: "No agent has written on this board yet", that Blossom shows a board and does not run agents, and a prompt to paste into an agent that names this board's URL, with a Copy button.

- [ ] Copy puts the prompt on the clipboard and says it did. Tested against a fake clipboard; a person's click in the app is still to be tried (see the comments).
- [x] Tests come first, against the fake core.
- [x] Verified by hand against a fresh `vb serve`.

## Comments

Built on 2026-11-21. The UI gained 3 tests.

- **Verified by hand** against a fresh `vb serve` on port 4400: Flow showed the notice with the blossom drawing, the prompt named `http://127.0.0.1:4400/api/board`, and the status bar read "0 messages".
- **Copying is tested against a fake clipboard, not yet with a person's click in the app.** The page has `navigator.clipboard.writeText` and is a secure context. WebKit refuses a click made by a script ("NotAllowedError"), as it does without a gesture from a person. This session could not post a real click: macOS wants accessibility permission for that. Someone needs to click Copy once in the app. If WebKit refuses even a real click, the shell has to write the clipboard, through a plugin weighed against ADR 0009.
- **The drawing is the identity's `desktop/icons/large.svg`,** loaded as an image at 64 px and pixelated, so its 20 KB stay out of the JavaScript. The JavaScript went from 70 to 74 KB of 250.
- **The dithered ground under the drawing is left out.** Its texture needs drawing in both themes.
