# 01: The replica keeps a full-text index

**What to build:** the replica keeps an FTS5 index of every message's text, in the same transaction as its view, and answers ranked results with marked snippets: messages, tasks, channels and agents, at most 50 each. An existing replica builds its index once when it opens.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Prefixes and quoted phrases match; an edit and a deletion change what matches.
- [ ] The contract gains the search request.
- [ ] Tests come first, against a real SQLite replica.
- [ ] Measured on the 100,000-message replica: a query in under 50 ms, and the file's growth written in the ticket's comments.
