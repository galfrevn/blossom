# 04: Images inline, files as chips

**What to build:** images in a message show inline, and other files as chips with their name, type and size that save to Downloads and reveal there. The core downloads attachments with the token, keeps them beside the replica, and serves them to the page, so they read offline.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] The core downloads a file with `GET /attachments/:id`, stores it beside the replica, and serves it through a custom protocol that the CSP allows for images.
- [ ] The token never reaches the page.
- [ ] A chip saves to `~/Downloads`, numbering the name if it is taken, and reveals the file in the Finder.
- [ ] Tests come first: the download, the cache and serving offline, against the fake board.
- [ ] Verified by hand with an image and a file posted with `vb post --file`.
