# 01: The pane opens a thread from the replica

**What to build:** the frame gains the concept's detail pane, beside the lens. Selecting a line in Flow opens its thread there: the root and every reply, oldest first, each with its author, the person it acts for and its time, as plain text for now. The pane follows the thread as replies arrive. Esc closes it.

**Blocked by:** Flow 02

**Status:** ready-for-agent

- [ ] The core answers a thread from the replica through an index on `(thread, created_at)`, and a subscription that follows it.
