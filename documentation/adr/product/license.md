# Apache-2.0 for the whole project

The project is open source for the community and is licensed under Apache-2.0. It is the license `@vercel/board` and GPUI use, it carries an explicit patent grant, and it does not slow adoption inside companies.

## Considered options

- **MIT.** Shorter, but with no patent grant.
- **AGPL.** It would force hosted forks to stay open, at the cost of scaring off use in companies. Rejected because adoption matters more here than protection from forks.
