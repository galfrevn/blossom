# Triage labels

The skills speak in terms of five canonical triage roles. This repository uses the default strings for all five, written on the `Status:` line of a ticket.

| Role | String | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate this ticket |
| `needs-info` | `needs-info` | Waiting on the reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an agent working alone |
| `ready-for-human` | `ready-for-human` | Requires a person to implement it |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill mentions a role, use the string from this table.
